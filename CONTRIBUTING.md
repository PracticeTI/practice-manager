# Contributing

Thanks for your interest in contributing to Practice Manager. The project is
being established, so development setup and contribution-specific checks will
be documented here as they become available.

## Before contributing

- Check existing issues and discussions before starting substantial work.
- For a significant change, open an issue or discussion first so the approach
  can be agreed on.
- Keep contributions focused and include relevant documentation updates.
- Do not submit confidential, patient-identifying, or otherwise sensitive data.
- Ensure you have the right to contribute the code and content you submit, and
  identify dependencies with licenses that may be incompatible with AGPL-3.0.

## Developer Certificate of Origin

Contributions are accepted under the Developer Certificate of Origin 1.1.
Include a `Signed-off-by` trailer in each commit to certify that you have the
right to submit the contribution:

```text
Signed-off-by: Your Name <your.email@example.com>
```

You can add the trailer with `git commit -s`. See
[developercertificate.org](https://developercertificate.org/) for the DCO
text.

## Pull requests

Describe the problem and the change, link related discussion, and note any
validation you performed. The project will publish build, lint, and test
instructions when those checks are in place.
